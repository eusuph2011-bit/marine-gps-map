Map settings & layers

Depth contours, soundings, navigation aids, and nautical charts appear only if your selected chart provider supplies them. This app does not invent depth data. Confirm licences and coverage before navigation.

Offline use

The app shell can be cached, but full offline maps need an authorized regional tile package or local tile server. Public OSM tiles must not be bulk-downloaded for offline use. The CDN Leaflet files also need to be bundled locally for a fully offline first launch.
